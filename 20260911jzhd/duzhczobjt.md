# 有流产史的孕妇唐筛是不是不容易通过？

> 更新时间：2026-09-11 (UTC+8)

是的，有流产史的孕妇唐筛是不容易通过。当然像年龄大的孕妇、有病毒感染史的孕妇以及染色体有异常的孕妇等在唐筛检查的时候都不容易过。唐筛也就是唐氏筛查，是唐氏综合征产前筛选检查的简称，是一种特殊意义的检查方法。目的是通过化验孕妇的血液，检测母体血清中甲型胎儿蛋白、绒毛促性腺激素和游离雌三醇的浓度，并结合孕妇的年龄、体重、孕周等方面来判断胎儿患先天愚型、神经管缺陷的危险系数。

什么人唐筛不容易通过

唐氏筛查是孕期非常重要的一项排畸检查，但是有很多孕妇都会发现自己的唐筛不过，其实像高龄孕妇、备孕期间有服药的孕妇已及时处于不良环境下工作的孕妇等，在唐筛检查的时候都有可能出现不过的情况。

- 1. 高龄孕妇由于身体的各项机能都在下降，而且很容易在孕期患有妊娠高血压、糖尿病，导致唐筛不容易通过，据研究表明25岁以下的孕妈妈怀唐氏儿的概率约为两千分之一，35岁以上的孕妈妈则为三百分之一，孕妈妈年事过了45岁生唐氏儿的概率则高达四非常之一；
- 2. 如果在备孕期间吃过孕妇慎吃的抗生素药物或是存在致畸可能性的药物，虽然是在备孕期间，但是很可能残留药物成分输送给胎儿，那么在唐筛过程中也很不容易通过；
- 3. 因为长期饲养宠物容易感染钩形虫，而钩形虫对胎儿的危害是非常大的，所以这类孕妇在唐筛检查的时候不容易通过，因此孕期的准妈妈们最好不要接触宠物；
- 4. 受孕时要是夫妻一方染色体有异常，那么怀的胎儿患唐氏症的几率也会相对更高。一般医生都会建议年龄大于35岁的孕妇孕期做羊膜穿刺检查，以检测胎儿有没有染色体异常；
- 5. 如果夫妻双方任一方有唐氏综合征基因携带者，那么胎儿很大几率也携带唐氏致病基因，导致孕妇在唐筛的时候不容易通过；
- 6. 如果夫妻双方有任一方长期在放射性环境下，例如化学放射性物质或是在污染风险较大的环境下工作，都有可能导致身体存在放射性致畸微量元素，这样也是不容易通过唐筛的；
- 7. 有过流产史或是因为胎儿的原因终止妊娠的孕妇，在怀孕之后也是很不容易通过唐筛检查的。

据了解，有流产史的孕妇唐筛是不容易通过，当然，像以上几类人群在唐筛的时候，也是不太容易过的，因此建议孕妇在怀孕期间，一定要注意。
