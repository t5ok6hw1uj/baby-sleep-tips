# 不舍、感动、感恩

> 更新时间：2026-09-16 (UTC+8)

可能是因为我们即将的离去，黄冈昨晚闪电、雷鸣、暴雨……天空都在为我们哭泣。而我，失眠到凌晨，早上6:30就醒了……带着复杂的心情和队友一起收拾好行李，当要离开时，发现有太多的不舍，这一个月我们白衣为袍为之战斗过的地方！清好行李后将酒店房间整理整洁，尽量不给他们添麻烦。收拾完毕，大家自发来到酒店一楼，为酒店工作人员送上自己的祝福和感谢，并合唱了一首《再见》，我想我内心的情感，就在此时爆发出来了吧。一首《再见》，泪流满面。黄冈，这个我曾经奋战过的地方；黄冈，这个我曾经挥洒过眼泪与汗水的地方；黄冈，这个我曾经拼过命的地方；黄冈，我的第二故乡……就在即将要转身离开之际，我的心中对你是万般的不舍。

当汽车在黄州大道缓缓行驶前进中，路边一排又一排的居民朋友们，有坐着轮椅的老人，头发都白了；有抱在怀里的小孩，或许还在咿呀学语；有环卫工人；有的士司机等等……他们都是自发地来为我们送行，举着横幅，挥舞着国旗，对我们竖起大拇指，喊着口号感谢我们的付出，十里送别“湘军”。可能大家今天的泪点都变得很低，我看到每个人都在抹眼泪，这一幕幕动人的画面，深深地印在了我的脑海里，让我越发舍不得黄冈这片充满爱的地方。就这样，一路上被所有的人与事感动着，泪水也未曾干过……为什么我的眼里常含泪水？因为我对这土地爱的深沉！

当下了高铁踏上长沙这片土地时，我远远的看到了我们湖南省省领导的迎接队伍、看到了我们妇幼大家庭，带着他们满满的关爱，来接我们了。我们情不自禁，异口同声的喊到：长沙，我们回来了；省妇幼，我们回来了！我对我的战友说：“感觉自己像是做了一场梦，来时做梦，归时依然在做梦。”这种场面新中国历史上出现了四次：一次是十里长街送总理；一次是98抗洪送子弟兵；一次是汶川灾后送子弟兵；一次是接送援鄂医护人员回家！我们作为援鄂医护人员，享受到了最高礼遇！

作为医护人员，救死扶伤是我们的职责所在。无论是在黄冈，还是在长沙，我们都做着自己的本职工作。当国家有难，组织有需要时，我们必将第一时间冲锋在前！
