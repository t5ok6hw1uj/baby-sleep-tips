# 全民营养周丨肾病患者如何吃出健康？低蛋白饮食了解一下

> 更新时间：2026-09-17 (UTC+8)

今年5月15日-5月21日是我国全民营养周，全民营养周旨在全社会宣传营养健康理念，使大众了解食物、提高健康素养、建立营养新生活，让营养意识和健康行为代代传递，提升国民健康素质。

很多慢性肾功能衰竭患者，由于均被要求低蛋白饮食，所以有25%～50％患者表现为低蛋白血症。绝大多数患者认为低蛋白饮食就是少吃甚至不吃鱼、肉、蛋、奶类等优质蛋白的食物，但这往往容易造成患者营养不良，影响疾病的治疗。

如何调整各类肾病患者的饮食蛋白方案，使之既能满足患者营养的需求，又不引起蛋白质代谢产物蓄积导致的肾脏负担，一直是医学界和临床营养学界长期关注的话题。

临床研究发现，慢性肾病患者实施低蛋白饮食，尤其是极低蛋白饮食治疗时，如果采用麦淀粉或低蛋白米等含极少量蛋白质的食物作为主食，既能保证优质蛋白质的摄入量达到50％以上，同时不造成肾脏负担。

采用低蛋白饮食，一方面可以在限量范围内提高优质蛋白质摄入的比例，另一方面也保证了低蛋白饮食的情况下摄入充足的能量。

  “麦淀粉”指的是将小麦粉（或玉米粉、大米粉、土豆粉、红薯粉）中的蛋白质进行抽离加工的淀粉，俗称“生粉”。

**优点：**价格便宜，并且可以制做成形式多样的食品，如凉皮、水晶饺、水晶包、水晶月饼、肠粉、烙饼、蛋糕等。
**缺点：**口感偏硬。适当掺入低筋面粉或米粉，可以改善口感。

低蛋白米是低谷蛋白低磷米。
目前市场上有两种低蛋白米：一种是国产天然大米，通过生物酶技术将米中的蛋白质去掉而制成的低蛋白米。这种米保留了部分的营养成分，其优点是口感好，与普通稻米的口感差别不大；缺点是价格相对较高。 另一种是淀粉低蛋白米，是采用玉米淀粉或者小米淀粉等脱蛋白挤压成型的颗粒米，其优点是经济实惠；缺点是口感不好，有一点特殊的味道，有些病人较难接受；如果将淀粉低蛋白米和普通大米搭配使用，可改善口感。

**肾衰竭患者用麦淀粉或低蛋白米代替主食有什么好处呢？**
一是在坚持低蛋白饮食的情况下，可以保证每天摄取充足的能量；
二是在限量范围内减少劣质蛋白的摄入，提高优质蛋白的比例。麦淀粉含蛋白质含量极少（0.3％～0.5％），明显低于大米（8％）和面（9.9％）的蛋白质含量，几乎可以忽略。
慢性肾功能衰竭病人用麦淀粉或低蛋白米代替主食，所节约的蛋白质就可用鱼肉蛋奶类优质蛋白质补充，从而提高了必需氨基酸的摄入，有利于减少植物蛋白的摄入和含氮废物的积累，达到减轻肝肾负担、延缓肾功能恶化、改善蛋白质营养不良、减少并发症、增强身体抵抗力的目的。
