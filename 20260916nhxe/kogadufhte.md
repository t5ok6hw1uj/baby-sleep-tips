# 试管，准备好了吗？

> 更新时间：2026-09-16 (UTC+8)

在国内试管婴儿不是你想做就可以做，要符合相关的适应症才可以。那么试管婴儿的适应症有哪些?

1. 输卵管因素（输卵管梗阻、粘连、积水等）

2. 排卵障碍

3. 子宫内膜异位症合并不孕

4. 男方因素

5. 反复人工授精助孕失败

6. 卵巢功能减退、高龄

前提：必须符合卫生部规定试管婴儿的相关指征。准备好结婚证、身份证、符合相关法律的承诺书，保证治疗过程合理合法。

自从试管助孕以来，相信很多人都常听到医生用这样一句话来回答各种各样的问题，那就是“正常生活”。“医生，移植完是不是要一直躺着？“”医生，移植完是不是不能开车、不能做饭？”“医生，我要吃什么才会有帮助？”面对这些问题，我们的回答都是正常生活。所谓正常生活，其实就是该吃饭吃饭、该睡觉睡觉、该开车就开车。只要上班不是太累，那就正常去上班。适当运动，不要做重体力劳动，适当的多休息，不要因为做试管去刻意改变自己的生活习惯。放松心情，正常生活。

试管助孕，不单单是女方一个人的事，而是整个家庭的事。“正常生活”也是说给家人听的，试管助孕的人需要支持和关心，但有时候过分的关心容易变成一种甜蜜的负担：有些家里的长辈移植后不让患者下床；变着法儿的加餐；出一点血就大呼小叫让躺着不动的……这些除了加重患者的紧张心情，并没有什么益处。

关于饮食

饮食往往是患者最关心的问题。民间流传着各种所谓妙招，如吃榴莲能长内膜、喝豆浆能增加激素水平……若某种水果、食品有那么神奇的功效，医生干嘛还要安排病人吃药打针，何必到医院受罪呢？日常生活中的饮食起居需多加留心，多吃新鲜蔬菜水果，避免感冒发烧腹泻。同时，未经医嘱，严禁私自服用药物。进周开始促排后可以适当多吃点富含蛋白的食物，有的人爱吃肉就多吃点肉，爱吃鱼虾就多吃点鱼虾。移植后，有的人容易便秘的话，可以多吃点蔬菜和水果，促进肠胃蠕动。以前没怎么吃过的东西，尽量不要在这个阶段尝试，引起过敏、腹泻就得不偿失了。

关于作息

只要工作不是太忙太累，尽量不要辞职备孕。抛开金钱压力不说，精神上也更容易紧张。提前安排好复诊的时间，合理安排自己的工作，劳逸结合。孕产妇的凝血功能会比平常增强，容易形成血栓，所以要适当活动，促进血液循环，降低血栓形成的风险。男方从备孕开始就要戒烟戒酒，因为精子生成周期一般为三个月左右，所以备孕前三个月还需要加强体育锻炼，改善生活习惯，减少熬夜。同时要避免接触高温环境，不要蒸桑拿。取精前需禁欲3-7天。

夫妇确定通过试管婴儿技术助孕后，女方会进入促排阶段。促排最常用的是长方案（月经第二十天左右开始降调，14天后开始促排卵，全过程大约需要1个月左右）和短方案（月经第二天开始促排卵，全过程大约需要2周左右）。当然还有其他的方案，如超长方案、拮抗剂方案、自然周期等。医生会根据个人的情况选择最合适的方案。

取卵前女方必查项目

阴道分泌物检查（阴道分泌物常规和衣原体、支原体、淋球菌），血液检查（血常规、输血常规、肝肾功能、甲状腺功能、基础性激素、凝血功能和血型），染色体，女方全套，心电图，胸片，B超，TCT，输卵管造影（部分患者需要做）。

取卵前男方必查项目

精液常规，精液形态，支原体、衣原体、淋球菌，血液检查（输血常规、肝肾功能、血型），染色体，男方全套。

很多病人都会担心取卵很痛。其实不必紧张，我们医生的动作都会很温柔的，而且取卵前会采用局部麻醉。取完卵后，医生会告诉你什么时候回来移植胚胎。通常三天后进行鲜胚移植，或五天后进行囊胚移植。如果身体条件不合适移植，则在下次月经来2-4天来院复诊。
